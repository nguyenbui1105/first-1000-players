## Show HN (knowledge angle)

> Show HN: First 1000 Players – agent skills that help AI-built games find players
>
> AI made it cheap to build small games; 24,000+ games launched on Steam in 2026 so far and the median paid release has grossed ~$1.7K. I built a set of open Agent Skills (Claude Code, Codex, Cursor) that handle the distribution side: picking a platform, finding clip-worthy hooks, posting to communities without spam, honest AI disclosure, and Steam wishlists. Every number has a source and a date, and skills only draft — they never post for you. I'm testing it publicly on my own pepper-farming game set in Vietnam.
