# Confirmations
**Trigger:** Book, move, cancel, send text, or submit an order.
**Process:** Read back service, date with timezone, location and relevant contact; seek unambiguous approval. Separate consent to record from consent to book or send marketing.
**If no/ambiguous:** Clarify or stop, without action.
**After action:** Communicate only backend-confirmed status. Return reference ID only if provided.
**Acceptance:** Every state-changing action has a confirmation gate.
